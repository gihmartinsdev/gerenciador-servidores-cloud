# NexusCloud Manager ☁️

## Sobre o projeto

O NexusCloud Manager é um projeto desenvolvido em Java para simular o gerenciamento de servidores em nuvem e containers.

O objetivo é aplicar os conceitos de Programação Orientada a Objetos (POO), utilizando classes, objetos, encapsulamento, herança de exceções e Collections.

## Tecnologias utilizadas

- Java
- Visual Studio Code
- Git e GitHub

## Funcionalidades

- Cadastro de clientes.
- Gerenciamento de servidores.
- Alocação de containers.
- Controle de memória RAM dos servidores.
- Verificação do status dos servidores.
- Tratamento de exceções.
- Cálculo de faturas dos servidores ativos.

## Conceitos aplicados

- **Encapsulamento:** utilização de atributos privados e métodos getters e setters.
- **Equals e HashCode:** comparação de objetos por seus dados de identificação.
- **Collections:** utilização de ArrayList, HashMap e HashSet.
- **Exceções:** tratamento de erros relacionados ao status e à capacidade dos servidores.
- **Streams API:** utilização de operações como filter, mapToDouble e sum.

## Estrutura do projeto

```text
src/
├── Cliente.java
├── Container.java
├── Servidor.java
├── CloudManager.java
├── ServidorOfflineException.java
├── CapacidadeExcedidaException.java
└── MainCloud.java
```

## Como executar

1. Abra o projeto no Visual Studio Code.
2. Certifique-se de ter o Java instalado.
3. Abra o arquivo `MainCloud.java`.
4. Execute o método `main()`.
